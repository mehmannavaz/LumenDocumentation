# LunarDocumentation
A static HTML, easy to deploy or share and don't have other documentation problem. Fork, Upgrade, Share.

## Getting started:
Just run the `Lumen_documentation.html` file, Open the setting and `start from scratch` and every time you wanna export it or save it as `.HTML format`
