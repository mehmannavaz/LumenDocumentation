    Update & Sync (GitHub)
    Fetches a lumen-data.json (or exported .html / .md) from your repo and saves it locally. The token stays in this browser only — use a fine-grained, read-only token.
    AI assist (optional)
    Any OpenAI-compatible endpoint works (OpenAI, OpenRouter, Ollama, LM Studio…). Select text in the editor, then press ✨ to improve, fix, summarize, or translate. The key stays in this browser only.
    Data management
    …
    Pages & settings live in localStorage; uploaded media lives in IndexedDB (much bigger). Snapshots keep the last 15 states.
    ⏱ Version history
    Snapshots are created automatically before destructive actions (delete, import, reset, remote update) and can be restored at any time. They live in this browser only — export a JSON backup to move them.
    ✨ AI
    Review the result, then apply it to the selected text in the editor. Ctrl+S saves the page.
